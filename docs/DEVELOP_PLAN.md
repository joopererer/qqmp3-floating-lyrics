# DEVELOP_PLAN.md

## 1. 项目定位与当前状态

- 项目名称：`qqmp3-floating-lyrics`
- 当前基线：`v0.1.0`（已完成 `qqmp3.vip` 播放状态与原生歌词时间轴读取、外部歌词检索、逐字解析与句间切换、Document PiP 跨标签页置顶小窗）[cite 3, 4]
- 核心原则：保持轻量可用；优先在浏览器用户脚本生态内打磨体验与交互细节，同时为未来跨桌面端透明悬浮扩展预留清晰的数据与渲染解耦边界。

## 2. 跨页面与透明毛玻璃技术路线确认

 路线  适用场景  跨页面跨窗口能力  透明与毛玻璃能力  维护成本 
 ---  ---  ---  ---  --- 
 路线 1：Document PiP（当前主线）  纯油猴脚本  浏览器扩展，零外部依赖  支持跨标签页及跨窗口置顶  受浏览器安全策略限制，不支持真透明与穿透毛玻璃  低 
 路线 2：脚本 + 本地桌面伴侣端  追求真透明、无边框、低占屏与系统级毛玻璃  支持全系统窗口置顶与跨应用显示  支持透明背景、无边框与系统级毛玻璃半透明  中高（需双端联调） 

- 短期策略：聚焦路线 1 的视觉专业度、自适应排版、可配置动效与歌词匹配体验。
- 中期远期策略：将“播放状态采集 + 歌词解析与时间对齐”抽离为独立状态模型，后续若需要真透明桌面歌词，可直接接入本地伴侣端。

## 3. 迭代路线图

### v0.2.0 — 专业化视觉排版与动态行距行数自适应
- 窗口高度自适应：根据 PiP 窗口高度自动切换单行紧凑、经典三行、多行滚动布局，减少非必要空间占用。
- 动态与可调行距：基于字号与窗口高度计算舒适行距范围，并提供行距档位调节。
- 可配置行切换动画：支持无动画（瞬切）、柔和淡入上浮等切换模式，并允许关闭调整动效。

### v0.3.0 — 播放器风格设置面板与本地持久化
- 精简交互入口：保持主视图干净，通过悬停点击唤出独立设置面板（避免杂乱控件常驻）。
- 参考主流播放器的核心设定：
  - 字体与字号、主副行层级对比
  - 主题配色与高亮未唱对比度
  - 歌词时间轴偏移微调（如 `-2.0s` 至 `+2.0s`）
- 配置持久化：使用 `GM_setValue`  `GM_getValue` 保存用户偏好。

### v0.4.0 — 多歌词源管理与手动搜词重匹配
- 手动搜索与重匹配：当自动识别歌曲信息偏差或未命中理想版本时，支持手动输入歌名歌手重新检索与绑定。
- 多源优先级与开关：支持管理歌词来源优先级与启用状态，完善无歌词纯音乐状态提示。

### v0.5.0  v1.0.0（可选）— 桌面透明毛玻璃伴侣端探索
- 设计本地通信协议（如 WebSocket），推送当前歌曲、进度、歌词行与逐字时间轴状态至独立桌面透明歌词窗口。

## 4. 推进规范

1. 先确认方案，再写代码：涉及交互结构、视觉风格或跨端方案变更时，先对齐方案与细节，再生成完整脚本或模块代码。
2. 向后兼容：新版本配置项提供合理默认值，确保老用户升级后开箱即用。
3. 版本与文档同步：每次发布新版本 tag 时，同步更新 `README.md` 与 `CHANGELOG.md`。
