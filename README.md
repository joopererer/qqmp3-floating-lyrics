# qqmp3-floating-lyrics

一个面向 `qqmp3.vip` 的浏览器用户脚本（Tampermonkey），利用 **Document Picture-in-Picture** 实现**跨标签页/跨窗口置顶悬浮歌词**，支持自适应行数与动态行距、三套视觉皮肤、封面智能取色背景、可选波形/Disco 氛围动效、三态听歌小人、双向播放控制同步以及手动搜词与时间轴校准[cite: 11]。

## 功能特性

- **跨窗口置顶悬浮**：通过 Document Picture-in-Picture 弹出独立置顶小窗，切换到其他网页或其他桌面窗口时依然可见[cite: 11]。
- **窗口尺寸自适应与动态行距**：拖动窗口边缘改变高度时，自动在**单行紧凑条**、**经典三行**与**多行滚动**之间切换，并根据窗口尺寸与字号动态计算行距（支持紧凑 / 标准 / 宽松三档调节）[cite: 11]。
- **左侧封面渐入与智能取色**：封面稳固靠左并随窗口尺寸自适应放大，右侧宽幅柔和渐隐；支持自动提取封面主色融入底色，营造通透的暗色毛玻璃层次（跨域图片自动回退预设主题色）。
- **三套皮肤与多主题配色**：内置 **克制面板风**、**Lyricify 灵感风** 与 **卡拉OK条风**，搭配深海青、暖金胶与极简浅色主题，支持上下滚动渐隐切行或无动画瞬切[cite: 11]。
- **氛围背景与状态角色**：可选开启 **Disco 氛围光斑**（默认）或 **动态波形** 背景，右下角配有随演唱中、间奏、暂停三态切换的极简听歌小人徽章。
- **顶部居中歌名栏与双向播控**：顶部栏居中显示当前歌曲名、歌手与歌词来源；鼠标移入窗口时显示**上一首、播放/暂停、下一首、播放模式（顺序/单曲/随机）**快捷控制（与网页端双向同步），点击 **「⚙️ 设置」** 可打开设置抽屉进行行距字号、手动搜词重匹配及 `±0.2s` 时间偏移微调，所有偏好自动本地持久化[cite: 11]。

## 安装与使用

1. **安装脚本管理器**：在最新版 Chrome 或 Edge 浏览器中安装 **Tampermonkey** 扩展[cite: 11]。
2. **导入脚本**：从 Greasy Fork 安装，或新建/更新油猴脚本并粘贴仓库中的 `qqmp3-floating-lyrics.user.js` 保存[cite: 11]。
3. **打开悬浮窗**：访问 `https://www.qqmp3.vip/` 播放音乐，点击右下角 **「🎤 置顶歌词」** 即可弹出置顶窗口[cite: 11]。
