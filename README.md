# qqmp3-floating-lyrics

一个面向 `qqmp3.vip` 的浏览器用户脚本（Tampermonkey），利用 **Document Picture-in-Picture** 实现**跨标签页/跨窗口置顶悬浮歌词**，支持自适应行数、三套视觉皮肤、专辑封面柔和渐入、悬停播放控制以及手动搜词与时间轴校准。

## 功能特性

- **跨窗口置顶悬浮**：通过 Document Picture-in-Picture 弹出独立置顶小窗，切换到其他网页或其他桌面窗口时依然可见。
- **窗口尺寸自适应**：拖动窗口边缘改变高度时，自动在**单行紧凑条**、**经典三行**与**多行滚动**之间切换，并根据窗口大小与字号动态计算行距。
- **三套皮肤与多主题配色**：内置 **克制面板风**、**Lyricify 灵感风** 与 **卡拉OK条风**，搭配深海青、暖金胶与极简浅色主题，支持柔和切行动画或无动画瞬切。
- **左侧封面柔和渐入**：自动读取当前歌曲封面并在左侧以宽幅渐变融入背景，不遮挡歌词与控制区。
- **悬停播放控制与设置抽屉**：鼠标移入窗口顶部显示**上一首、播放/暂停、下一首、播放模式**快捷按钮；点击 **「⚙️ 设置」** 可调节行距字号、手动搜词重匹配、切换皮肤配色及校准时间偏移（`±0.2s`），设置自动本地持久化。

## 安装与使用

1. **安装脚本管理器**：在最新版 Chrome 或 Edge 浏览器中安装 **Tampermonkey** 扩展。
2. **导入脚本**：新建或更新油猴脚本，粘贴仓库中的 `qqmp3-floating-lyrics.user.js` 并保存。
3. **打开悬浮窗**：访问 `https://www.qqmp3.vip/` 播放音乐，点击右下角 **「🎤 置顶歌词」** 即可弹出置顶窗口。
